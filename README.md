# 📊 Business Insights Report (EDA)

## 📌 Task Overview
Performed Exploratory Data Analysis (EDA) on the Titanic dataset
to uncover key business insights about passenger survival.

## 🛠️ Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Google Colab
- Dataset: Titanic Dataset (Kaggle)

## 💡 Key Insights
- Overall survival rate was 38.4%
- Female survival rate (74%) was much higher than male (19%)
- 1st class passengers had highest survival rate (63%)
- 3rd class passengers had lowest survival rate (24%)
- Average passenger age was 29.7 years
- Higher class = higher fare = better survival chances

## 📊 Visualizations
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Age Distribution of Passengers
- Average Fare by Class
